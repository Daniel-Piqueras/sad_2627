| malware | definicion |
|---------------|--------------------------------|
| Adware: |Software que muestra publicidad no deseada de forma automática (ventanas emergentes, banners) mientras se usa el equipo o se navega por internet.|
| Backdoor: | Código o método oculto que permite el acceso no autorizado a un sistema informático, saltándose los mecanismos habituales de autenticación.|
|Bomba Fork: |Tipo de ataque de denegación de servicio (DoS) en el que un programa se duplica a sí mismo de forma masiva hasta agotar por completo la memoria y los recursos del sistema, bloqueándolo.|
|Bots:| Programas automatizados que realizan tareas repetitivas. Cuando se usan con fines maliciosos, forman redes (botnets) controladas por atacantes para lanzar ataques o enviar spam.|
|Bug: |Error o fallo en el código fuente de un programa que puede provocar un comportamiento imprevisto o abrir vulnerabilidades de seguridad.|
|Caballo de Troya (Troyano): |Software malicioso que se disfraza de programa legítimo y útil para engañar al usuario y así instalarse y robar información o dañar el sistema.|
|Cookies:| Pequeños archivos de texto que los sitios web guardan en el navegador para recordar preferencias o sesiones. Nota: Aunque algunas cookies de seguimiento pueden ser invasivas con la privacidad, las cookies en sí mismas no son malware.|
|Crackers: |Personas que rompen o vulneran la seguridad de sistemas informáticos, redes o software con fines maliciosos (a diferencia de los hackers éticos).|
|Cryptovirus / Ransomware:| Malware que cifra los archivos del usuario y exige un pago (rescate) en criptomonedas o dinero para entregar la clave de descifrado.|
|Exploits: |Fragmentos de código o técnicas diseñadas para aprovechar un fallo de seguridad (bug) específico y comprometer un sistema.|
|Hijacker (Secuestrador):| Programa malicioso que modifica la configuración del navegador web (como la página de inicio o el buscador predeterminado) para redirigir al usuario a sitios publicitarios o maliciosos.|
|Hoax / Joke / Bulo: |Falsas alarmas o bromas informáticas que se propagan mediante mensajes engañosos (como cadenas de correo sobre virus inexistentes).|
|Keystroke / Keylogger: |Software o hardware que registra en secreto cada pulsación de teclado realizada por el usuario para robar contraseñas, números de tarjetas y datos confidenciales.|
|Ladilla virtual: |Término coloquial y poco común para referirse a programas molestos y difíciles de eliminar, similares al adware o software espía menor.|
|Leapfrog (Salto de rana): |Técnica en la que un atacante utiliza una máquina ya comprometida dentro de una red como trampolín para atacar otros sistemas más protegidos.|
|Parásito Informático: |Término genérico para cualquier programa que vive a expensas de los recursos de un sistema sin el consentimiento del usuario (como spyware o adware).|
|Pharming: |Técnica de ciberdelincuencia que redirige el tráfico de un sitio web legítimo a una página web falsa y fraudulenta para robar credenciales.|
|Phishing:| Estafa de ingeniería social en la que se suplanta la identidad de una empresa o entidad legítima (bancos, redes sociales) para engañar al usuario y robar sus datos personales.|
|Rabbit / Conejos:| Tipo de malware diseñado exclusivamente para multiplicarse con gran rapidez y consumir todos los recursos del sistema operativo hasta colapsarlo.|
|Riskware: |Software legítimo que puede representar un riesgo de seguridad si se configura incorrectamente o si es aprovechado por atacantes (por ejemplo, herramientas de administración remota).|
|Rootkit:| Conjunto de herramientas maliciosas diseñadas para ocultar la presencia de otro software (como troyanos o spyware) y otorgar privilegios de administrador al atacante, evitando su detección.|
|Scumware / Escoria: |Término informal para denominar a programas basura, no deseados e intrusivos, como barras de herramientas molestas o adware publicitario.|
|Spam:| Correo electrónico o mensajes masivos no solicitados, enviados por lo general con fines publicitarios o fraudulentos.|
|Spyware:|Software espía que recopila información sobre la actividad de un usuario en el equipo sin su conocimiento ni consentimiento.|
|Pop_Ups / Ventanas emergentes:| Ventanas que aparecen de manera repentina en el navegador. Aunque se usan legítimamente para formularios o avisos, a menudo son utilizadas por el adware para mostrar publicidad intrusiva.|
|Worms / Gusanos: |Malware autorreplicable que se propaga a través de redes informáticas de un equipo a otro, sin necesidad de infectar archivos anfitriones ni intervención humana directa. |
